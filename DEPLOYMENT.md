# Deployment checklist

- [ ] Confirm you have rights to publish all code, assets, and included data.
- [ ] Create a private or public GitHub repository as appropriate.
- [ ] Push the contents of this folder to the repository's `main` branch.
- [ ] Connect the repository to Render as a Blueprint.
- [ ] Configure a secured remote model endpoint if AI inference is required.
- [ ] Add persistent storage and production security before accepting real client documents.
- [ ] Test `/api/health` and `/api/health/model` after deployment.
